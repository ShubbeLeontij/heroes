# Герои

Компьютерная версия настольной игры «Герои» (Hobby World) с ИИ-игроками.
Правила — `docs/RULES.md`, карта — `docs/MAP.md`, план разработки — `docs/PLAN.md`.

## Запуск

```
python3 -m venv .venv && .venv/bin/pip install pytest   # один раз
.venv/bin/python -m heroes                               # мастер: число игроков и кто играет на каждом месте
.venv/bin/python -m heroes --players human,bot,bot       # без мастера: вы против двух случайных ботов
.venv/bin/python -m heroes --players human,bot --names Аня,Бот
.venv/bin/python -m heroes --players human,bot,bot --factions orcs,nagas,random   # вы за орков
.venv/bin/python -m heroes --players human,claude,claude   # вы против двух Claude (Opus 5.5)
.venv/bin/python -m heroes --players claude,claude --show-thoughts   # Claude против Claude
.venv/bin/python -m heroes --players human,claude --model claude-haiku-5-5   # дёшево, для отладки
.venv/bin/python -m heroes --load saves/2026-10-17_19-45-02_round05_auto.json   # продолжить сохранённую
.venv/bin/python -m heroes --gui                         # графический интерфейс (окно)
.venv/bin/pytest -q                                      # тесты
```

## Фракции

Все шесть фракций первой коробки: люди (`humans`), нежить (`undead`), гномы (`dwarves`), орки (`orcs`),
эльфы (`elves`), наги (`nagas`). Фракцию каждого места выбирает хозяин партии — в мастере (консоль),
флагом `--factions` или в окне «Новая партия», в том числе за сетевых гостей. Каждой фракцией играет только
один игрок, как в коробке; «случайная» (`random`, по умолчанию) — из тех, что никто не выбрал.

Особые механики фракций — ярость орков и Дом вождей, наука гномов, проклятия нежити, Лавка бронника эльфов,
краки, ноты и гидра наг — играются во всех клиентах: в консоли и в окне на каждое особое решение свой вопрос
или своя форма, Claude получает их описание и схему ответа, случайный бот пользуется ими наугад.

Консольный интерфейс, сетевой протокол и протокол Claude — на английском (по-русски только оригинальные названия
игры: регионы, здания, войска). Графический интерфейс — по-русски.
В игре: `/board`, `/map`, `/opponents`, `/log [N]`, `/save [file]`, `/quit`, `/help`.
Ресурсы: w — wood, i — iron, g — gold, a — any; действия: w i g m(ove) b(uild); да/нет — y/n.
Сохранения лежат в `saves/`, в имени — дата, время и номер раунда: `2026-10-17_19-45-02_round05.json`.
Автосохранение делается в начале каждого раунда (`…_round05_auto.json`; от партии остаётся только последнее),
прерванная по Ctrl+C партия сохраняется как `…_interrupted.json`.

Несколько людей играют за одним компьютером: перед ходом каждого появляется экран «<имя>'s turn»,
а после тайного выбора (перемещение, заявка войск) экран очищается.

Claude-игроки работают через установленный Claude Code CLI (`claude -p`). Партия Opus — около $3–4
и 10–15 минут на каждого Claude-игрока. Диалоги с Claude — в `logs/claude/`, замыслы Claude
печатаются флагом `--show-thoughts` (по умолчанию — только в партиях без человека).

## Графический интерфейс

`python -m heroes --gui` открывает окно (Tkinter, входит в Python; на Debian/Ubuntu может понадобиться
`sudo apt install python3-tk`). Со стартового экрана можно начать новую партию (люди за этим окном, боты,
Claude, люди по сети), продолжить сохранённую или подключиться к чужой.

- Слева карта — оригинальный рисунок из правил, подписанный как заполненная карта на планшете людей: значок
  местности (точками — регионы для 3+ и 4 игроков), название, ресурсы первого посещения (уже полученные —
  бледные), у крепости — сила (щит), ПО (венок) и добыча. В правом нижнем углу — дорожка стоимости
  перемещения, как на планшете («2»1» — что даст здание или артефакт; действующая для вас стоимость — яркая).
- Карта у каждого игрока своя, как его планшет: стрелками нарисован его маршрут (последнее перемещение —
  тёмное, прежние — бледные), в фундаментах вписан уровень его зданий, у захваченной им крепости — флажок.
  Карта показывается того игрока, чей планшет открыт справа: переключив планшет, вы видите и его карту.
  Объекты лежат отдельным слоем: захваченная кем угодно крепость и взятый артефакт с карты исчезают.
  Фишки игроков и «Б» (бронь Башни иллюзий) — цветом игрока; вычеркнутые при таком числе игроков регионы
  стёрты с карты целиком. Под картой — панель текущего решения; при выборе региона (старт, перемещение, Башня иллюзий)
  доступные регионы обведены и подписаны стоимостью, остальные притушены.
- Ресурсы в окне показаны иконками с планшета (дерево, железо, золото, сундук — любой ресурс), сила
  крепостей и чудовищ — щитом, ПО на карте и планшете — венком. Ярость, наука, краки, ноты и проклятый
  регион — значками из памятки, гидра наг — рисунком из правил.
- Особенности фракций на планшете: ярость орков — ячейкой склада с порогами ПО 12/18/24, наука гномов — шкалой
  0–18 с порогами бесплатных зданий, ноты и гидра наг, проклятые регионы нежити, блок «Свойства фракции»;
  у наг — своя линия чудовищ и свои условия артефактов. На карте гидра — фишкой с рисунком в цвете владельца,
  проклятый регион — значком проклятия, регион, ставший озёрным от Гейзера, — голубой штриховкой.
- Сила заявки на сражение считается по правилам фракции: краки, механики, прибавки к силе (Горн, Металка);
  отдельно стоящая гидра заявляется только одна.
- Справа планшет любого игрока, оформленный как печатный: склад с отметками ПО, войска, здания по уровням
  (тексты со значками ресурсов, местности, силы войск, ярости, науки, краков и нот), артефакты с рисунками,
  линия чудовищ с рисунками. Цена найма видна у всех войск, и у тех, что пока нанять нельзя, — с подсказкой,
  какое здание для этого нужно. При строительстве доступные здания на планшете обведены оранжевым: щелчок
  по карточке выбирает здание (повторный — снимает выбор), так же, как переключатель в панели решения.
  На вкладке «Все игроки» — пять таблиц: регион, ресурсы и войска; ПО по категориям; здания по уровням;
  победы, захваченные крепости и артефакты; условия артефактов и насколько каждый игрок их выполнил
  («3 / 4», ✓ — выполнено, «взят»). Двойной щелчок по строке — планшет и карта игрока.
- Игрок везде в окне (списки, таблицы, панели решений, журнал, итоги) упоминается с фракцией: «Аня (Люди)».
- Журнал событий — отдельное окно поверх игры: кнопка «События» над планшетом (или Ctrl+E, меню «Игра»)
  открывает и закрывает его; пока оно закрыто, на кнопке видно число новых событий.
- На полосе вверху — фазы раунда: выбор порядка действий, затем четыре действия; текущая подсвечена, прошедшие
  бледные. Пока ход за другими, панель решения пишет, кто чем занят: «Claude (Люди) выбирает порядок действий
  раунда…», «Боря (Люди) тайно заявляет войска на сражение в регионе Цурт…» (тайные решения — у нескольких сразу).
- Под ней — строка очерёдности: игроки по порядку хода в этом раунде (первый выбирает действия; в этом порядке
  объявляют регионы и идут сражения), кто сейчас решает — подсвечен, и кто будет первым в ближайших раундах
  (первым становится сосед слева). До первого раунда — порядок выбора стартовых регионов.
- Порядок действий раунда: щелчок ставит действие на первое свободное место, мышью его можно перетащить
  на любое место (или поменять два местами); правая кнопка по выбранному действию или перетаскивание
  за пределы мест — убрать.
- Несколько людей за одним окном: перед решением другого игрока окно просит передать ему экран.
- Сохранение — меню «Игра → Сохранить» (Ctrl+S, новый файл в `saves/` с датой и номером раунда); автосохранение —
  как в консоли. «Продолжить последнюю партию» на стартовом экране открывает самое свежее сохранение.
- Панель решения — постоянной высоты (границу с картой можно сдвинуть мышью), карта от хода к ходу не прыгает.
- Сразу подключиться или загрузить: `python -m heroes --gui --join 192.168.1.5 --name Боря`,
  `python -m heroes --gui --load saves/<файл>.json`.

### Профили игроков

Стартовый экран → «Профили игроков» (или меню «Игра»). На одном компьютере может быть сколько угодно профилей;
хранятся они в `profiles/` рядом с `saves/`.

- В профиле — имя, аватарка и статистика. Аватарка — своя картинка (PNG или GIF: обрезается до квадрата
  по центру и скругляется) или, если её нет, силуэт.
- Активный профиль (★) показан на стартовом экране. Он садится на первое место «Человек» в новой партии,
  и с его именем вы подключаетесь к сетевой. Каждому человеку за этим окном мастер предлагает выбрать
  профиль из списка или вписать новое имя — тогда профиль с этим именем создаётся сам при старте партии.
- В статистику попадают только доигранные партии: запись появляется после подсчёта очков. Партия,
  загруженная из сохранения и доигранная ещё раз, не дублируется. Гость сетевой партии получает запись
  на своём компьютере, в свой активный профиль. Консольная партия пишется в профиль, если имя человека
  совпадает с именем профиля.
- В записи о партии для вас и для каждого соперника: фракция, номер хода (место в очерёдности: 1 — первый
  игрок первого раунда) и ПО; победитель отмечен. Соперники показаны с аватарками (см. ниже).

### Аватарки в партии

Аватарка стоит перед именем игрока везде в окне: полоса вверху и строка очерёдности, список планшетов,
таблицы «Все игроки», журнал событий, панели решений, экран передачи хода, итоги. На карте фишки игроков —
их аватарки (вдвое крупнее прежних кружков с буквой); у фишки того, чья карта открыта, чёрная обводка.

- Человек — своя аватарка из профиля. Её видят все: хозяин рассылает аватарки своих профилей, а гость
  присылает аватарку активного профиля при подключении. Без своей картинки — силуэт в цвете места.
- Claude — человечек, которого Claude Code показывает в начале новой сессии; бот — робот. Оба в цвете
  места за столом.
- Исключения, где картинки не бывает: заголовок окна и строки списка регионов при перемещении
  («сейчас там: …»).

## Игра по сети

Партия идёт на компьютере хозяина: там же играют боты и Claude. В мастере выберите для гостя
«человек по сети» и задайте имя — или без мастера:

```
.venv/bin/python -m heroes --players human,remote,claude --names Аня,Боря,Claude --password сова
```

Хозяин увидит команду для гостей. Гостю нужна копия проекта и Python 3.12+ (venv не обязателен):

```
python3 -m heroes --join 192.168.1.5 --name Боря --password сова         # в терминале
python3 -m heroes --gui --join 192.168.1.5 --name Боря --password сова   # в окне
```

Хозяин тоже может открыть партию из окна (`--gui` → «Новая партия» → «Человек по сети»).
Гости в окне и в терминале могут сидеть за одним столом; переподключиться можно любым из двух клиентов.

- Версия сетевого протокола — 3: хозяину и гостям нужна одна и та же версия игры.
- Порт по умолчанию 7777 (`--port`). Через интернет нужен проброс порта или общая VPN-сеть (например, Tailscale).
- Сетевые игроки видят события партии сразу, а тайные решения принимают одновременно.
- Если связь оборвалась, партия ждёт: гость переподключается той же командой и видит текущий вопрос.
- `/выход` любого игрока прерывает партию для всех; хозяин может продолжить её из сохранения
  (`--load`), гости подключатся заново.
- Пароль передаётся открытым текстом — это защита от случайных подключений, а не шифрование.
