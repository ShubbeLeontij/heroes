# Герои

Компьютерная версия настольной игры «Герои» (Hobby World) с ИИ-игроками.
Правила — `docs/RULES.md`, карта — `docs/MAP.md`, план разработки — `docs/PLAN.md`.

## Запуск

Партию создаёт хозяин в терминале; там же идут движок, боты и Claude. Люди — и сам хозяин — играют в браузере
на телефоне, планшете или компьютере: страницу раздаёт игра хозяина, устанавливать ничего не нужно.

```
python3 -m venv .venv && .venv/bin/pip install pytest   # один раз
.venv/bin/python -m heroes                               # мастер: число игроков, кто играет на каждом месте и т. д.
.venv/bin/python -m heroes --players human,bot,bot       # без мастера: человек против двух случайных ботов
.venv/bin/python -m heroes --players human,bot --names Аня,Бот --password сова
.venv/bin/python -m heroes --players human,bot,bot --factions orcs,nagas,random --first random
.venv/bin/python -m heroes --players human,claude,claude   # человек против двух Claude (Opus 5.5)
.venv/bin/python -m heroes --players claude,claude --show-thoughts   # Claude против Claude
.venv/bin/python -m heroes --players claude,claude --watch           # то же, а смотреть — в браузере
.venv/bin/python -m heroes --players human,claude --model claude-haiku-5-5 --effort low   # дёшево, для отладки
.venv/bin/python -m heroes --load saves/2026-10-17_19-45-02_round05_auto.json   # продолжить сохранённую
.venv/bin/python -m heroes --continue                    # продолжить самую свежую
.venv/bin/python -m heroes --profiles                    # только страница «Профили и статистика»
.venv/bin/pytest -q                                      # тесты
```

Хозяин увидит ссылку для каждого человека — с его именем и паролем, например
`http://192.168.1.5:7777/?name=Аня&password=сова`: её открывают в браузере (свою — и сам хозяин), и партия
начинается, когда все сели за стол. Мастер спрашивает всё то же, что флаги: число игроков, кто на каждом месте
(человек, Claude, случайный бот), имена, фракции, модель и effort Claude, печатать ли замыслы Claude, порт и пароль,
кто ходит первым.

## Фракции

Все шесть фракций первой коробки: люди (`humans`), нежить (`undead`), гномы (`dwarves`), орки (`orcs`),
эльфы (`elves`), наги (`nagas`). Фракцию каждого места выбирает хозяин партии — в мастере или флагом
`--factions`, в том числе за людей. Каждой фракцией играет только один игрок, как в коробке; «случайная»
(`random`, по умолчанию) — из тех, что никто не выбрал.

Особые механики фракций — ярость орков и Дом вождей, наука гномов, проклятия нежити, Лавка бронника эльфов,
краки, ноты и гидра наг — играются у всех: в браузере на каждое особое решение своя форма, Claude получает
их описание и схему ответа, случайный бот пользуется ими наугад.

Терминал хозяина, сетевой протокол и протокол Claude — на английском (по-русски только оригинальные названия
игры: регионы, здания, войска). Страница в браузере — по-русски.
Сохранения лежат в `saves/`, в имени — дата, время и номер раунда: `2026-10-17_19-45-02_round05.json`.
Автосохранение делается в начале каждого раунда (`…_round05_auto.json`; хранятся все — можно вернуться к любому раунду).
Сохранить посреди раунда, не прерывая партию, — команда `save` (или `save <файл>`) и Enter в терминале хозяина;
Ctrl+C сохраняет партию как `…_interrupted.json` и останавливает её у всех.

Claude-игроки работают через установленный Claude Code CLI (`claude -p`). Партия Opus — около $3–4
и 10–15 минут на каждого Claude-игрока. Тайные решения (перемещение, заявка войск в сражении) все Claude
принимают одновременно; перемещение наги и её гидры — одним вопросом, а модификацию войск Лавкой бронника
эльф называет вместе с заявкой. Диалоги с Claude — в `logs/claude/`, замыслы Claude печатаются в терминале хозяина флагом `--show-thoughts` (по умолчанию — только в партиях без человека).

В крупных решениях Claude получает свой планшет и сводку по соперникам. Полный планшет любого игрока
(здания с ценами и свойствами, артефакты, цены найма, линия чудовищ, стоимость перемещения) он может
запросить в любом вопросе полем `view_boards` — тогда получает планшеты и тот же вопрос ещё раз
(каждый планшет — один раз за решение). Тайные ответы соперников на планшетах не видны: они попадают
в состояние партии, только когда ответили все.

### Как Claude учится

Опыт ведётся отдельно для каждого варианта Claude — модели и уровня усилий (`--effort`):
`strategy/<модель>/<effort>/` (`default` — без `--effort`). Папка `strategy/` — рабочая копия ветки `strategy`
этого же репозитория (git worktree): коммиты Claude-игроков идут в неё, а не в `master`. Игра сама
подключает папку при первом разборе партии (`git worktree add strategy strategy`), пушить —
`git push origin strategy`. Устройство описано в `strategy/README.md`.

- **Заметки по фракциям** (`<фракция>.md`): разделы «General strategy», «Reminders» и «Against <фракция>».
  Файл своей фракции Claude получает в системном промпте. После партии он может, но не обязан, переписать
  общий раздел, напоминания и разделы против соперников, с которыми играл (против случайного бота — нет).
  Длина ограничена: общий раздел — 2000 символов, против фракции — 800.
- **Напоминания** — строки `- [<когда>] <текст>`, не больше 12. «Когда» — через запятую: `always`,
  `round N`, `rounds N-M` и виды решений (`build_recruit`, `destination`…). Подходящие напоминания движок
  вставляет прямо в вопрос. Claude правит их после партии, чтобы они срабатывали в нужный момент.
- **План и разбор.** Перед первым решением Claude продумывает план против выпавших фракций (`game_plan`),
  после партии разбирает свою игру (`game_review`). План виден в журнале, только если показываются
  замыслы; разбор показывается всегда.
- **История.** Каждое изменение заметок и скриптов — коммит: тема — объяснение Claude, тело — итог партии
  и разбор. Перед правкой Claude видит три последних изменения своего файла (с диффами) и скриптов.
- **Результаты** — `strategy/results.csv`: по строке на каждого Claude-игрока в каждой партии (вариант,
  фракция, ПО, место, соперники).
- **Путаница в правилах** — `strategy/RULES_CONFUSION.md`, для человека: ответы, отклонённые движком,
  ответы не по формату и вопросы о правилах, которые Claude задаёт сам (поле `rules_unclear`).

**Инструменты** (Linux, нужен `bwrap`; отключить — `--no-tools`). Claude работает из своей копии папки
`scripts/` варианта: пишет там Python-скрипты и ведёт их `README.md`, запускает их командой
`heroes-run <скрипт.py>`, а в скриптах симулирует следующие ходы на копии движка (`heroes/sim.py`:
срез партии на момент вопроса, свои ответы и стратегии соперников, очки после симуляции). Скрипты
работают в песочнице bwrap: без сети, писать можно только в рабочую папку, логи, сохранения, заметки
и сессии соперников не видны. Claude Code запускается с `--restricted`: файловые инструменты видят
только рабочую папку и код игры, из Bash разрешена только `heroes-run`. После партии изменения скриптов
возвращаются в общую папку варианта; если тот же файл изменил другой Claude этого варианта, вторая
версия кладётся рядом (`README.orcs.md`). С инструментами вызовы дольше и дороже, тайм-аут — 15 минут.

## Экран в браузере

Страница — для телефона (вертикально и горизонтально), планшета и компьютера. На экране подключения — имя
(место за столом), пароль партии и своя аватарка (картинка из галереи или снимок); имя, пароль и аватарка
запоминаются в браузере. Там же кнопки «Смотреть партию» и «Профили и статистика».

- Телефон вертикально: карта сверху, под ней открытая вкладка («Решение», «Планшеты», «Журнал»), вкладки внизу;
  вкладка «Карта» — карта на весь экран. Горизонтально: карта слева, вкладки справа. На широком экране
  всё видно сразу, журнал открывается кнопкой «События».
- Карта — оригинальный рисунок из правил, подписанный как заполненная карта на планшете людей: значок
  местности (точками — регионы для 3+ и 4 игроков), название, ресурсы первого посещения (уже полученные —
  бледные), у крепости — сила (щит), ПО (венок) и добыча, дорожка стоимости перемещения, как на планшете.
  Карта у каждого игрока своя, как его планшет: его маршрут стрелками, уровень его зданий в фундаментах,
  флажок у захваченной им крепости; показывается карта того, чей планшет открыт. Фишки игроков — их аватарки.
  Два пальца (или колесо мыши) — масштаб, палец — сдвиг увеличенной карты, двойной тап — вся карта,
  тап по региону — выбор, долгое нажатие — фишки полупрозрачны (видно, что под ними).
- При выборе региона (старт, перемещение, Башня иллюзий) доступные регионы обведены и подписаны стоимостью.
  Пока при выборе порядка действий перемещение стоит на месте N, карта показывает, куда её хозяин дойдёт с N ОП.
- Планшеты — вкладка на каждого игрока и сводка «Все игроки» (регион, ресурсы и войска; ПО по категориям;
  здания; победы, крепости и артефакты; условия артефактов, у эльфов — и за дерево). Планшет оформлен как
  печатный: склад с отметками ПО, войска с ценой найма и силой после модификаций («1»2»), здания по уровням,
  артефакты и линия чудовищ с рисунками, особенности фракций (ярость, наука, ноты, гидра, проклятия).
  При строительстве и бое с чудовищем доступное обведено на планшете: тап выбирает здание или чудовище.
- Порядок действий раунда: тап ставит действие на первое свободное место, его можно перетащить на другое место
  или за пределы мест — убрать.
- Сила заявки на сражение считается по правилам фракции; модификацию Лавкой бронника эльфы называют в той же
  форме. Заведомо проигрышный штурм крепости или бой с чудовищем движок не принимает (у всех: человек, Claude,
  бот) — кнопка доступна, только когда заявленной силы хватает. Сражений между игроками это не касается.
- Вверху — фазы раунда и строка очерёдности: кто сейчас решает и кто будет первым в ближайших раундах. Пока ход
  за другими, панель решения пишет, кто чем занят («Боря (Люди) тайно заявляет войска…»).
- Игрок везде упоминается с фракцией: «Аня (Люди)».
- Связь рвётся (телефон уснул, сменилась сеть) — страница подключается сама и получает текущий вопрос.
  Если телефон пропал молча, хозяин замечает это за 45 секунд.
- Ярлык на рабочем столе: в меню браузера «Добавить на главный экран» — страница откроется без адресной строки.
- Внутри: страница — `heroes/web/static/` (JS без сборки), сервер — `heroes/net/web.py` (HTTP и WebSocket на stdlib),
  русские тексты журнала готовит `heroes/web/ru.py`.

### Зрители

«Смотреть партию» на экране подключения — партия целиком, без места за столом и без чьих-либо тайн: так
хозяин смотрит партию Claude против Claude (флаг `--watch` открывает её для браузеров и без людей за столом).

### Профили и статистика

Профили хранятся на компьютере хозяина (`profiles/`), а смотрят и правят их в браузере — кнопка «Профили
и статистика» на экране подключения и в итогах партии. Если у партии есть пароль, он нужен и здесь.

- Профиль человека — по его имени за столом (без учёта регистра). Доигранная партия записывается в профиль
  каждого человека; если профиля ещё нет, хозяин заводит его сам — с аватаркой, с которой человек играл.
  Партия, загруженная из сохранения и доигранная ещё раз, не дублируется.
- В профиле — имя, аватарка и статистика: партии, победы, средние и лучшие ПО, и по карточке на каждую партию:
  для вас и каждого соперника — фракция, номер хода (место в очерёдности: 1 — первый игрок первого раунда) и ПО;
  победитель отмечен.
- На странице профиля можно поменять имя и картинку, удалить профиль, а «Играть под этим профилем» запоминает
  в браузере его имя и аватарку для подключения. Новый профиль можно завести и вручную.
- Страница работает, пока у хозяина запущена игра: после партии с людьми она остаётся открытой, пока хозяин
  не нажмёт Enter; без партии — `python -m heroes --profiles` (адрес `http://<хозяин>:7777/#profiles`).

### Аватарки

Аватарка стоит перед именем игрока везде на странице, а на карте заменяет фишку. Человек — своя картинка
(её присылает браузер; если её нет — картинка его профиля у хозяина, иначе силуэт в цвете места). Claude —
человечек, которого Claude Code показывает в начале новой сессии; бот — робот. Оба в цвете места за столом.

## Игра по сети

Партия идёт на компьютере хозяина, браузеры подключаются к нему. Порт по умолчанию 7777 (`--port`).

- В одной сети достаточно ссылки, которую печатает хозяин. Через интернет нужен проброс порта или общая
  VPN-сеть (например, Tailscale).
- Люди видят события партии сразу, а тайные решения принимают одновременно.
- Если связь оборвалась, партия ждёт: браузер переподключается сам и видит текущий вопрос.
- Хозяин прерывает партию по Ctrl+C — она сохраняется, продолжить её можно с `--load` или `--continue`
  (браузеры подключатся заново; пароль задаётся заново флагом).
- Пароль передаётся открытым текстом — это защита от случайных подключений, а не шифрование.
- Версия сетевого протокола — 5; страницу раздаёт хозяин, поэтому её версия всегда совпадает с версией его игры.
