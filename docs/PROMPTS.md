# Что Claude-игрок получает в вопросах

Каждый вопрос — один вызов `claude -p --resume <сессия>`: модель видит **всю прошлую переписку партии** (системный
промпт, все прошлые вопросы, свои ответы и запуски инструментов) и новое сообщение. Поэтому входных токенов на вызов
много больше, чем весит само сообщение: сообщение — 6–9 тыс. символов, а вход к середине партии — 150–300 тыс. токенов
и растёт с каждым вопросом.

Ниже: сначала блоки, из которых собираются сообщения, потом — каждый вопрос: когда задаётся, что даётся, что
ответить. Размеры (≈ символов) сняты со стенограммы партии орков 31.10, раунд 8–9.

Код: `heroes/protocol/prompts.py` (сборка), `render_text.py` (планшеты), `schemas.py` (формат ответа), тексты
вопросов — в движке (`heroes/engine/`). Как это связано с заметками и разбором партии — `CLAUDE_FLOW.md`.

## Блоки

### Один раз — системный промпт (≈ 30 тыс.)

| Блок | Что внутри | ≈ |
|---|---|---|
| Кто ты | фракция, имя, номер, соперники и их фракции, рассадка | 0,2 тыс. |
| ПРАВИЛА | `docs/RULES_ENG.md` целиком | 10,7 тыс. |
| ОСОБЫЕ ПРАВИЛА | `strategy/RULES_SPECIAL_ENG.md`: уточнения компьютерной версии, их дописывает Claude | 2 тыс. |
| СВОЯ ФРАКЦИЯ | свойства фракции, цена движения, войска (сила, цена, стартовое число), дерево строительства (все здания: уровень, ПО, цена, требования, эффект), своя линия чудовищ | 1,6 тыс. |
| ПЛАНШЕТЫ СОПЕРНИКОВ | по каждому сопернику — всё то же, что в СВОЕЙ ФРАКЦИИ: свойства, цена движения, войска (сила, цена, стартовое число), дерево строительства целиком, своя линия чудовищ | 2–2,5 тыс. на соперника |
| АРТЕФАКТЫ | по каждому из 6 артефактов: условие получения (цена) и эффект — для себя и для каждого соперника, эффект помечен «разовый» или «постоянный»; что бывает с артефактом, отнятым в бою | 2,4 тыс. |
| КАРТА | регионы в игре: местность, ресурсы, объект, соседи; порталы; линия чудовищ | 3,5 тыс. |
| ЗАМЕТКИ | `strategy/<модель>/<усилия>/<фракция>.md`: стратегия по фракции и против соперников, напоминания | 0,1–3 тыс. |
| ИНСТРУМЕНТЫ | только если инструменты включены: скрипты, `heroes-tool`, симуляция, код движка | 2,3 тыс. |
| ВРЕМЯ | лимит на ответ; «думай минутами над ключевыми решениями» | 0,4 тыс. |
| ПРОТОКОЛ | сначала анализ текстом, потом JSON; `rules_unclear`; «играй на победу» | 0,8 тыс. |

### В каждом вопросе

| Блок | Что внутри | ≈ |
|---|---|---|
| СОБЫТИЯ | журнал партии с прошлого вопроса; пропущенные вопросы: «You were not asked …, потому что …» | 0,1–0,6 тыс. |
| ПЛАНШЕТ | свой планшет: регион, склад и обведённые отметки, ярость/наука/ноты/гидра, свойства фракции, войска (сила, цена найма, можно ли нанять), дерево строительства со статусом (✓ построено, + можно построить), артефакты со статусом, фундаменты, крепости, линия чудовищ, цена движения, ПО «если бы игра кончилась сейчас» | 3,1 тыс. |
| СОПЕРНИКИ | по каждому кратко: регион, склад, войска и общая сила, особые шкалы, построенные здания (только названия), артефакты, крепости, победы, ПО | 1 тыс. |
| КАРТА СЕЙЧАС | кто где стоит, гидры, изменённые регионы (захваты, артефакты, брони, проклятия, фундаменты), местность после Гейзера, где ты был и где ещё нет | 1,2 тыс. |
| КРАТКО | раунд, первый игрок, порядок действий и твой склад — одной строкой | 0,1 тыс. |
| НАПОМИНАНИЯ | напоминания из заметок, подходящие к раунду и виду вопроса | 0–0,5 тыс. |
| ВОПРОС | текст движка — свой у каждого вида, см. ниже | 0,1–0,6 тыс. |
| ВАЖНО | «EVERY DECISION MATTERS…» — одинаковый у всех вопросов | 0,2 тыс. |
| ФОРМАТ | как ответить и JSON-схема ответа | 0,2–1,9 тыс. |
| ПОДСКАЗКА | только с инструментами: список `heroes-tool` и `heroes-run` | 0,2 тыс. |

**Полный контекст** = СОБЫТИЯ + ПЛАНШЕТ + СОПЕРНИКИ + КАРТА СЕЙЧАС. **Краткий** = СОБЫТИЯ + КРАТКО.
Дальше в любом вопросе: НАПОМИНАНИЯ, ВОПРОС, ВАЖНО, ФОРМАТ, ПОДСКАЗКА. Какой контекст у вопроса — список `MAJOR`
в `prompts.py`.

## Вопросы

Вопрос, где выбора по факту нет (вариант один или прочие заведомо бессмысленны), движок не задаёт: ответ берётся
сам, а Claude узнаёт об этом строкой в СОБЫТИЯХ. Ниже это «не задаётся, если …».

### Начало партии

**План на партию** · `game_plan` · без контекста
- Когда: перед самым первым решением, вместе с системным промптом.
- Даётся: кто играет за соперников (человек, бот, Claude); просьба продумать:
  - свой план: экономика, порядок зданий, цели (чудовища, крепости, артефакты), примерные сроки, стартовый регион;
  - соперников по их планшетам: как каждый скорее всего будет играть, какие здания будет строить первыми и к какому
    раунду, как его игра изменится после них; за какими событиями следить и как на них отвечать;
  - артефакты: цена и эффект для себя и для каждого соперника; какие брать самому и когда, какие не отдать
    сопернику, какие не стоят того.
- Ответ: план текстом, до ≈2500 символов.

**Стартовый регион** · `choose_start` · полный
- Когда: подготовка, по очереди против часовой стрелки.
- Даётся: свободные регионы с порталом.
- Ответ: регион. Не задаётся последнему, если остался один.

### Раунд

**Порядок действий** · `action_order` · полный
- Когда: начало раунда, только первому игроку.
- Даётся: 5 действий; место в порядке = уровень действия.
- Ответ: 4 действия по порядку.

**Разложить «любой ресурс»** · `distribute_resources` · краткий
- Когда: получен 🎁 (чудовище, регион, крепость, награда); у людей с артефактом Таскар — при каждом получении дерева
  (его можно взять железом и золотом).
- Даётся: откуда ресурсы и сколько.
- Ответ: раскладка по дереву, железу, золоту.

### Строительство и наём

**Строительство и наём** · `build_recruit` · полный
- Когда: действие строительства, по порядку хода.
- Даётся: уровень действия; склад вместе с яростью, наукой, краками; здания, которые можно построить сейчас (уровень,
  ПО, цена, эффект); фундамент в регионе; цена найма каждого войска; у орков — пути модификации и Дом вождей;
  у гномов — Библиотека; «шаги действуют сразу, один даёт ресурсы следующему».
- Ответ: список шагов (`build`, `hire`, `upgrade`, `raise`, `science`), в конце `done`. Без `done` — тот же вопрос
  снова, с новым состоянием. ФОРМАТ здесь самый большой (≈1,9 тыс.): схема со всеми зданиями и войсками фракции.
- Ситуации:
  - повторный вопрос в том же действии — плюс «уже сделано в этом действии»;
  - шаг не выполнился — плюс «NOT PERFORMED: шаг — причина», сделанное до него осталось;
  - здание в этом действии уже построено — список зданий не показывается;
  - не задаётся, если ничего нельзя ни построить, ни нанять, ни модифицировать.

**Башня иллюзий (люди)** · `reserve_object` · полный
- Когда: конец строительства, если хватает на оплату.
- Даётся: цена; объекты, которые можно забронировать (регион и тип объекта).
- Ответ: регион или `none`.

**Проклятие (нежить)** · `curse_region` · полный
- Когда: конец строительства с Чумным столбом (можно отказаться) или от артефакта (обязательно).
- Даётся: цена; регионы, которые можно проклясть; что делает проклятие.
- Ответ: регион; от Чумного столба можно и `none`.

### Перемещение

**Куда идти** · `destination` · полный
- Когда: действие перемещения; все выбирают тайно и одновременно.
- Даётся: ОП и текущий регион; достижимые регионы: местность, объект, был ли там, проклят ли, цена, сколько ОП
  останется; «оставшиеся ОП позволяют пропускать чудовищ».
- Ответ: регион.
- Ситуации:
  - орки с Домом вождей, нежить с Катафалком — плюс как повысить действия / купить ОП и какие регионы откроются при
    +1, +2… ОП; ответ `{destination, raise, buy}`;
  - наги с гидрой отдельно — в том же сообщении второй вопрос `hydra_destination` (куда гидре, на 1–2 шага);
    ответ на оба сразу;
  - не задаётся, если ОП не хватает ни на один соседний регион.

**Гейзер (наги)** · `make_lake` · краткий
- Когда: конец перемещения, если остались ОП.
- Даётся: регион, его местность, остаток ОП.
- Ответ: да / нет.

**Заявление в регионе** · `region_stance` · полный
- Когда: в регионе несколько игроков; по порядку хода.
- Даётся: кто рядом и их войска с силой; кто что уже заявил; объект региона; свои войска; варианты (`fight`, `claim`,
  `pass` — только те, что ведут к разным исходам).
- Ответ: вариант. Не задаётся, если бой уже неизбежен.

**Откуп от боя (наги)** · `avoid_battle` · полный
- Когда: сейчас начнётся бой, а у наги есть Шахта.
- Даётся: сколько ресурсов отдать каждому сопернику; свой склад.
- Ответ: раскладка оплаты или отказ.

**Заявка в бою с игроками** · `commit_army` · полный
- Когда: бой между игроками; все заявляют тайно и одновременно.
- Даётся: участники; свои войска с силой; «заявленные гибнут все, при ничьей проигрывают все»; гидры в этом бою.
  Войска соперников — в блоке СОПЕРНИКИ. У эльфов — Лавка бронника: сколько модифицировать, в том же ответе.
- Ответ: сколько войск каждого вида (можно 0). Не задаётся, если войск нет.

**Награда за победу** · `choose_reward` · полный
- Когда: победа в бою с игроками.
- Даётся: добыча обведённого чудовища; ресурсы проигравших (сколько всего и что у кого есть); их артефакты.
- Ответ: вид награды и что взять. Не задаётся, если вариант один.

**Штурм крепости** · `capture_fortress` · краткий
- Когда: после боёв, если ты один в регионе с незахваченной крепостью.
- Даётся: сила крепости, добыча, ПО; свои войска с силой; «заявку, которой не победить, движок не примет»; Лавка
  бронника у эльфов.
- Ответ: штурмовать ли и кем.
- Ситуации: гидра наги одна у крепости — штурмует только она, добыча теряется. Не задаётся, если не взять даже всеми.

**Бой с чудовищем** · `fight_monster` · краткий
- Когда: конец перемещения.
- Даётся: чудовища, до которых можно дотянуться (сила, ПО, добыча; сколько можно пропустить за оставшиеся ОП;
  у нежити с Алтарём — любое); свои войска с силой; «заявку, которой не победить, движок не примет»; Лавка бронника.
- Ответ: биться ли, с кем и кем.
- Ситуации: гидра наги отдельно — второй такой вопрос, только про неё и только с первым необведённым чудовищем.
  Не задаётся, если никого не победить даже всеми.

**Взять артефакт** · `take_artifact` · краткий
- Когда: после всех боёв, если ты один в регионе с артефактом и условие выполнено.
- Даётся: эффект артефакта для твоей фракции, цена (или «условие выполнено»).
- Ответ: да / нет.

### Особые вопросы фракций

| Вопрос | Фракция | Контекст | Даётся → ответ |
|---|---|---|---|
| `circle_note` | наги | краткий | ноты по парам → открыть пару или закрыть (и призвать гидру) |
| `summon_hydra` | наги | полный | озёрные регионы → куда призвать гидру |
| `exchange_on_gain` | нежить | краткий | сколько железа получено, Часовня → обменять ли 3 на палача |

Claude не задаются (остались для старых сохранений и ботов): `raise_action`, `buy_move_points` — теперь часть
`destination`; `battle_upgrade` — Лавка бронника называется в заявке.

### Конец партии

**Разбор** · `strategy_notes` · свой набор
- Даётся: последние события, итоговые очки, кто играл за соперников, текущие заметки, отчёт об инструментах, история
  заметок в git.
- Ответ: разбор игры; по желанию новые разделы заметок, уточнения правил; недостающие инструменты. Подробно —
  `CLAUDE_FLOW.md`.

### Когда что-то пошло не так

| Случай | Что уходит Claude |
|---|---|
| Движок отклонил ответ | «YOUR PREVIOUS ANSWER WAS REJECTED: причина» + тот же ВОПРОС + ВАЖНО + ФОРМАТ. Без контекста и напоминаний |
| Ответ не по схеме | только «Could not parse your answer (…). Answer the same question strictly by the schema.» |
| Claude не ответил за лимит | тот же вопрос ещё раз (до 3 попыток), потом движок берёт ответ по умолчанию |
