# Запуск в терминале

Запуск — `python -m heroes` (или `.venv/bin/python -m heroes`). Терминал всегда хост: в нём идут движок, боты и Claude,
а люди, включая самого хозяина, играют в браузере.

## Пять режимов

| Команда | Что делает |
|---|---|
| `python -m heroes` | Мастер новой партии: вопросы по шагам |
| `python -m heroes --players …` | Новая партия без мастера, всё задаётся флагами |
| `python -m heroes --load <файл>` | Продолжить сохранённую партию |
| `python -m heroes --continue` | Продолжить самое свежее сохранение |
| `python -m heroes --profiles` | Только страница «Профили и статистика», без партии (работает до Ctrl+C) |

## Состав партии (новая партия)

- **`--players human,claude,bot`** — от 2 до 4 мест по часовой стрелке:
  - `human` — человек в браузере;
  - `claude` — Claude через Claude Code CLI;
  - `bot` — случайный бот.
- **`--names Аня,Claude,Бот`** — имена по местам. Имена не должны совпадать (без учёта регистра). Человек
  подключается со своим именем, и по нему же находится его профиль. Без флага имена будут «Player 1», «Claude 1»,
  «Bot 1».
- **`--factions orcs,random,nagas`** — фракции по местам: `humans`, `undead`, `dwarves`, `orcs`, `elves`, `nagas`
  или `random`. По умолчанию у всех `random`. Каждой фракцией играет только один игрок, а `random` выбирается
  из тех, что никто не взял.
- **`--first N` или `--first random`** — кто ходит первым: номер места с 0 или случайно. По умолчанию 0.
- **`--seed N`** — зерно случайных ботов, чтобы партию можно было повторить.

## Claude

- **`--model`** — модель, по умолчанию `claude-opus-5-5`. Ещё есть `claude-sonnet-5-5` и `claude-haiku-5-5`
  (дёшево, для отладки).
- **`--effort low|medium|high|xhigh|max`** — уровень усилий. По умолчанию — `max`. Партии, начатые до 0.6.0 без
  `--effort`, после загрузки продолжаются с уровнем модели по умолчанию. Системный промпт называет Claude лимит
  времени на ответ (10 минут без инструментов, 15 с ними) и просит думать над ключевыми решениями по несколько минут.
- **`--tools` / `--no-tools`** — дать ли Claude свои скрипты и симуляцию партии в песочнице bwrap. По умолчанию —
  если bwrap установлен. В начале партии в журнал печатается по строке на каждого Claude-игрока: модель, усилия и
  включены ли инструменты (`tools on` / `tools off` с причиной); в стенограмме `logs/claude/<сессия>.jsonl` у каждого
  вызова есть поля `analysis`, `tools_enabled` и `tokens` (входные с кэшем, выходные и из них — на размышления);
  пересказ партии (анализ и решение Claude на каждом вопросе) — в `logs/claude/<сессия>.story.md`. В конце партии
  по каждому Claude-игроку печатаются число вызовов, стоимость и токены за партию.
- **`--show-thoughts` / `--no-show-thoughts`** — печатать ли замыслы Claude в терминале хозяина. По умолчанию —
  только в партиях без людей.
- Если за столом есть Claude, а `claude` не установлен, партия не начнётся.

## Браузер и сеть

- **`--port N`** — порт сервера, по умолчанию 7777. На нём же раздаётся страница.
- **`--password слово`** — пароль партии. Он нужен и для подключения, и для страницы профилей.
- **`--watch`** — открыть партию для зрителей, даже когда людей за столом нет, например для Claude против Claude.
  Если люди есть, сервер запускается в любом случае, и зрители могут подключиться через «Смотреть партию».

## Сохранения

- **`--autosave папка`** — куда автосохранять в начале каждого раунда, по умолчанию `saves/`. `--autosave ''`
  отключает автосохранение.
- **`--load <файл>` / `--continue`** — продолжить партию. Состав, имена, фракции, модель и effort берутся
  из сохранения, а флаги `--players`, `--names`, `--factions`, `--first`, `--model`, `--effort`, `--tools`
  и `--seed` не действуют. Порт, пароль, `--show-thoughts`, `--watch` и `--autosave` действуют. Пароль
  в сохранении не хранится, его нужно задать заново.

## Мастер (без `--players`)

Вопросы идут по порядку:

1. Сколько игроков (2–4).
2. Для каждого места: кто играет, имя, фракция. По умолчанию первое место — человек, остальные — боты, фракция
   случайная. Мастер предупреждает, если имя или фракция уже заняты, и показывает профили, которые уже есть.
3. Если за столом есть Claude: модель и effort (по умолчанию `max`). Вопрос пропускается, если модель или effort заданы флагом.
   Если за столом есть и люди, мастер ещё спрашивает, печатать ли замыслы Claude.
4. Если за столом есть люди: порт и пароль. Значения флагов предлагаются по умолчанию.
5. Кто ходит первым, по умолчанию случайно.
6. Итоговый состав и «Start? [Y/n]».

Ctrl+C или «n» отменяют партию.

## Что происходит после запуска

1. Хост печатает для каждого человека ссылку с его именем и паролем, например
   `Аня: http://192.168.1.5:7777/?name=Аня&password=сова`, и адрес для зрителей. Потом ждёт, пока все люди
   подключатся.
2. Во время партии в терминале идёт журнал по-английски. Там же работают команды:
   - `save` и Enter — сохранить партию, не прерывая её;
   - `save <файл>` — сохранить в указанный файл;
   - Ctrl+C — сохранить как `roundNN_interrupted_….json` и остановить партию у всех.
3. После партии хост:
   - печатает итоговую таблицу;
   - записывает партию в профили людей (если профиля нет, он заводится);
   - запускает разбор партии у Claude и печатает его расходы.

   Если играли люди, страница остаётся открытой для итогов и статистики, пока хозяин не нажмёт Enter.

## Примеры

```
python -m heroes --players human,claude,claude --names Аня,Claude1,Claude2 --password сова
python -m heroes --players human,human,bot --factions elves,orcs,random --first random
python -m heroes --players claude,claude --watch --effort high
python -m heroes --players human,claude --model claude-haiku-5-5 --effort low --no-tools
python -m heroes --continue --password сова
```
